JavaScript is the programming language of the web. Every modern browser runs it, and with **Node.js** it also runs on servers, in command-line tools and even in desktop and mobile apps. If you want to build anything for the web, JavaScript is the language to learn first.

## What can JavaScript do?

- **Make web pages interactive** — respond to clicks, validate forms, show and hide content, animate elements.
- **Talk to servers** — fetch data from APIs and update the page without reloading it.
- **Run back-end services** — with Node.js you can build web servers, REST APIs and real-time apps.
- **Build full applications** — frameworks such as React and Angular are written in (and for) JavaScript.

## HTML, CSS and JavaScript

A web page is usually built from three languages, each with its own job:

| Language | Role | Example |
| --- | --- | --- |
| HTML | Structure and content | A heading, a button, a form |
| CSS | Presentation | Colours, layout, fonts |
| JavaScript | Behaviour | What happens when you click the button |

## A first taste

Here is a tiny program. Don't worry about the details yet — every part of it is covered in later lessons.

```js
const name = 'World'
const greeting = `Hello, ${name}!`

console.log(greeting) // Hello, World!
```

- `const name = 'World'` stores a piece of text in a **variable** called `name`.
- The backticks create a **template string** that inserts the value of `name`.
- `console.log` prints a value to the console.

## JavaScript is not Java

Despite the name, JavaScript and Java are unrelated languages. JavaScript was created at Netscape in 1995; the name was largely a marketing decision. Today the language is standardised as **ECMAScript**, and a new edition is published every year.
